# MapMyApps

Personal map for places you share from Instagram, Pinterest, Facebook, and other apps.

Places stay in the browser on your phone. This repo is only the app shell.

## Phone setup

1. On GitHub, open this repo, Settings, Pages, and deploy from the `main` branch, root. The app will be at `https://delirioustub.github.io/MapMyApps/`.
2. Open that link in Safari and add it to your Home Screen.
3. In Shortcuts, create a shortcut named MapMyApps.
4. Tap the info button and turn on Show in Share Sheet. Accept URLs, Safari web pages, and text.
5. Add a URL Encode action on the Shortcut Input.
6. Add Open URLs. The URL is `https://delirioustub.github.io/MapMyApps/?add=` plus the encoded input.
7. Share a post, tap MapMyApps, search the place, save the pin. Go opens Apple Maps directions.

Route on a list previews the drive, then opens Apple Maps through the stops.
